# 拆段复刻后台任务

原视频上传完成后将任务交给独立 Node 进程。画布只负责上传、查询和显示，关闭页面不取消切分、逐段生成或结果下载。当前仅使用本机 Muse 接口与服务器保存的登录配置，不复制浏览器密钥。

每个任务保存原视频、精确 10 秒分段（尾段保留实际长度）、任务清单及结果 MP4。清单通过临时文件与原子重命名写入；每段先保存 submitting，再提交 Muse，再保存任务编号。若进程在提交期间终止且没有编号，暂停并要求核对，禁止自动重提。已有编号恢复查询，已完成段不重做。每个任务用进程锁防止重复运行。

任务中心可请求当前段完成后暂停。查询失败保留编号，继续时查询原任务；供应商明确失败时显式重试该段。沿用现有 2500 毫秒查询间隔、120 次查询限制及模型最小时长约束。

服务启动和进度读取时恢复未完成的活动任务。画布按项目读取任务，并以稳定的任务/片段节点编号同步结果。视频存本机，不依赖临时外部链接；支持 Range 播放。停止本机服务或关闭电脑期间无法生成；已保存的阶段可在下次启动恢复，提交状态未知时仍保持暂停。

每段提交前提取首、中、尾帧交给已登录的 Codex，以位置和服装区分人物并分析遮挡，不识别真实身份。自动附加遮挡保留规则，优先于旧提示词中对完整五官的要求；观察仅基于采样，未观察时刻以参考视频为准。分析失败暂停，分析结果和实际提示词原子保存，恢复时不重复分析已保存段。
