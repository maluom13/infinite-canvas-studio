# 本机 Muse 登录接入

目标：在新版 Infinite Canvas 内完成 Muse 登录、模型选择与生成，不要求用户手工配置 API。

采用现有 Muse 服务的登录窗口与 OpenAI 兼容生成接口，避免重复管理账号和浏览器登录态。方案在新版顶部增加 Muse 入口，并在现有配置对话框增加 Muse 标签。用户可以使用已有账号，也可以打开登录窗口或重新登录；成功后自动配置图片与视频模型。

本地 Vite 插件只向已安装的回环服务转发白名单接口，并注入服务端读取的本机密钥。网页不取得真实密钥；请求检查 Host、Origin 和 Fetch Metadata。作品依然使用新版画布的数据目录。没有移植其他画布的界面、修改共享账号凭据或绕过服务授权。

保留上游服务的登录状态轮询间隔，不增加生成重试、并发数或新的任务时限。接口错误展示在 Muse 面板中，用户可刷新或重新登录。关闭设置面板不打断进行中的登录状态查询。

验证覆盖：账号元信息脱敏、跨站拒绝、登录转发、multipart 引用图传递、媒体 URL 与 Range 返回、上游错误保留；浏览器检查默认模型、持久化、登录状态和模拟生成链路。真实登录与生成需要用户进一步验证。原项目 TODO 已检查，本机接入没有完成或删除其中的既有条目。
